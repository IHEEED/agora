# PARAFRAZ — как запустить

Соцсеть с сообществами, постами, голосованием и комментариями.
Фронтенд — Next.js, бэкенд — Express, база и авторизация — Supabase.

## Что нужно

- **Node.js 20+** (проверить: `node -v`). Если его нет — https://nodejs.org
- Проект **Supabase** (бесплатного тарифа хватит) — https://supabase.com

## 1. Установить зависимости

```bash
cd backend && npm install && cd ../frontend && npm install
```

## 2. Завести базу

В панели Supabase откройте SQL Editor и выполните содержимое `backend/schema.sql` —
он создаёт таблицы сообществ, постов, комментариев и голосов.

## 3. Прописать переменные окружения

Скопируйте примеры и подставьте свои ключи из Supabase
(Project Settings → API):

```bash
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env.local
```

- `SUPABASE_SERVICE_KEY` — это **service_role** ключ. Он обходит Row Level Security,
  поэтому живёт только в `backend/.env` и никогда не попадает во фронтенд.
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` — публичный **anon** ключ, его можно отдавать браузеру.

## 4. Запустить

Два терминала:

```bash
cd backend && npm run dev
```

```bash
cd frontend && npm run dev
```

Фронтенд поднимется на http://localhost:3000, API — на http://localhost:4000.

## Структура

- `frontend/` — Next.js: лента, профиль, поиск сообществ, уведомления
- `backend/` — Express API: `/communities`, `/posts`, `/comments`, `/votes`
- `mobile/` — заготовка мобильного приложения
- `design/parafraz-feed.svg` — макет ленты в светлой и тёмной теме, импортируется в Figma

## Что пока не реализовано на бэкенде

Эти элементы есть в интерфейсе, но серверной части у них нет — счётчики живут
только в состоянии компонента и сбрасываются при перезагрузке:

- **Истории** (полоса сториз наверху ленты) — собирается из авторов постов,
  своих историй загружать некуда
- **Репосты** — кнопка и счётчик работают локально, таблицы репостов нет
- **Уведомления** — экран есть, событий с сервера не приходит
- **Картинки в постах** — карточка отрисует `image_url`, если поле придёт,
  но API его сейчас не отдаёт
