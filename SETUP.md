# Продолжить на другом устройстве

Два способа перенести проект. Первый лучше, второй — когда интернета нет.

---

## Способ 1: из GitHub

```bash
git clone https://github.com/IHEEED/agora.git
cd agora
git checkout redesign-parafraz
```

Ветка `redesign-parafraz` — рабочая, вся свежая работа в ней. `main` отстала.

## Способ 2: из архива

Двойной щелчок по `BACKUP.cmd` в корне проекта. Он кладёт `parafraz-ГГГГ-ММ-ДД-ЧЧММ.zip`
в папку `parafraz-архивы` рядом с проектом — около пяти мегабайт.

Внутри всё, включая историю git: на новом месте это не россыпь файлов, а
репозиторий, из которого можно сразу продолжать и пушить. Не входят
`node_modules` и `frontend/.next` — это два гигабайта, которые восстанавливаются
одной командой из `package-lock.json`.

---

## Ключи

Их нет ни в git, ни в архиве. Это не забывчивость: ключ `service_role` обходит
все правила доступа к базе, а архивы копируют, пересылают и забывают на чужих
флешках.

Два файла надо создать на новом месте руками:

| Файл | Что внутри |
|---|---|
| `backend/.env` | `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `PORT` |
| `frontend/.env.local` | `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `NEXT_PUBLIC_API_URL` |

Образцы полей лежат рядом: `backend/.env.example`, `frontend/.env.example`.
Значения берутся заново в панели Supabase → **Project Settings → API**.

Для мобильного клиента ещё `mobile/.env` — см. `mobile/.env.example`.

---

## Запуск

```bash
cd frontend && npm install
cd ../backend && npm install
```

Дальше два окна терминала:

```bash
cd backend && npm run dev
```

```bash
cd frontend && npm run dev
```

Фронт на `localhost:3000`, бэкенд на `localhost:4000`.

**Посмотреть на телефоне:** `phone.cmd` в корне — собирает рабочую версию,
поднимает обе половины и печатает адрес для iPhone. Подробности и ограничения —
в `PHONE.md`.

## Миграции

Выполняются руками в Supabase → SQL Editor, целиком, по порядку номеров. Лежат
в `backend/migrations/`.

Приложение переживает невыполненную миграцию: без неё возможность просто не
работает, а остальное продолжает. Это сделано намеренно — один раз добавленная
в запросы колонка, которой ещё нет в базе, обрушила весь список переписок, и с
тех пор бэкенд при старте спрашивает базу, что в ней есть (`config/schema.ts`).

**Как проверить, что уже применено** — по наличию того, что миграция заводит:

| Номер | Что заводит | Признак в базе |
|---|---|---|
| 015 | приглашения, модерация, блокировки | таблица `invites` |
| 016 | развод одинаковых ников при регистрации | — |
| 017 | лица у людей | колонка `users.avatar_url` |
| 018 | закрепить и приглушить переписку | таблица `chat_prefs` |
| 019 | облачко с мыслью на сутки | таблица `notes` |

После 017 бэкенд надо перезапустить: он спрашивает схему один раз при старте.
Если колонки нет, он скажет об этом строкой в журнале и просто выключит
аватарки.

## Болванки для разработки

С одним-двумя людьми половину интерфейса не на чем посмотреть: ошибки вроде
разъезжающихся ников видны только на количестве.

```bash
cd backend
node scripts/seed-people.mjs     # 10 человек и 7 переписок
node scripts/seed-stories.mjs    # 10 историй и лица (нужна 017)
node scripts/seed-demo.mjs       # записи с медиа и цепочками
```

У каждого есть `--clean`, чтобы убрать за собой.

## Что где лежит

| Папка | Что это |
|---|---|
| `frontend/` | Next.js — то, что видно в браузере |
| `backend/` | Express — говорит с Supabase, держит кеш и пул соединений |
| `mobile/` | Expo — нативный клиент, пока пять экранов из двенадцати |
| `backend/migrations/` | схема базы, по порядку номеров |
| `backend/scripts/` | болванки для разработки |

Отдельные документы: `ROADMAP.md` — что осталось до выпуска, `PHONE.md` — как
посмотреть на iPhone, `backend/DEPLOY.md` — хостинг, `mobile/BUILD-IOS.md` —
сборка под iOS.

## Проверить, что ничего не сломано

```bash
cd frontend
npx tsc --noEmit    # типы
npm run build       # сборка
npx eslint src      # придирки
```

```bash
cd backend && npm run build
```

Несколько предупреждений линта в `RollingNumber.tsx`, `PostMenuSheet.tsx` и
`settings/page.tsx` — давние и известные, они не про свежие правки.

## Оговорка про dev-сервер

Turbopack иногда отдаёт старый CSS-чанк: правка в `globals.css` есть в файле и в
собранной версии, но на экране её нет. Это не сломанная правка — перезагрузите
страницу. Проверять спорные случаи надёжнее по `npm run build`, а не по тому,
что показывает `npm run dev`.
